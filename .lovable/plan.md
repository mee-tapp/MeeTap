# Meetap Website

## Goal
Build a polished, responsive Meetap homepage inspired by the provided reference, using the supplied logo and a darker graphite/navy palette with white accents.

## What will be built
- A premium first screen with navigation, Meetap branding, a clear value proposition, and a natural-language recommendation search.
- Purpose shortcuts for Date, Friends, Study, and Alone, plus visible context filters for location, weather, budget, and distance.
- A curated recommendations area with category filters, venue cards, fit explanations, ratings, travel times, and save controls.
- A stylized map preview and compact history/future-feature content to communicate the full product vision without turning the page into a generic marketing site.
- Responsive layouts and working interactions for search, filters, favorites, and category switching.

## Visual direction
- Graphite and deep navy surfaces, clean white typography, restrained cool-blue accents, and subtle texture/light effects.
- Modern editorial typography, compact controls, crisp borders, and minimal rounded corners.
- Custom venue imagery that matches Istanbul social spaces and the supplied visual direction.

## Technical details
- Rebuild the `/` route in React using the existing TanStack Start setup.
- Define all color, typography, shadow, radius, and motion tokens in the global design system.
- Store the uploaded logo through the project asset flow and derive the site icon from it.
- Add unique homepage metadata and preserve accessibility, reduced-motion support, and mobile behavior.
- Verify the finished page in the running preview at desktop and mobile sizes and resolve build/runtime errors.

## Scope
This version delivers the complete frontend experience with realistic sample recommendations. Live AI, maps, weather, location, accounts, and saved-history persistence are not connected yet.
